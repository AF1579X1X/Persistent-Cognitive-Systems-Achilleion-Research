Epistemic Governance under Protocol V1

The constitutional and technical meaning of epistemic governance in ACHILLEION/Q_ANIMA, preserving the Protocol V1 Freeze and AUTHORITY=NONE.

1. Scope and constitutional position

This document is a dated public research statement with snapshot date 2026-08-04. The Protocol V1 Freeze remains in force. Protocol V2 has not been declared. AUTHORITY=NONE remains invariant. Governance here describes how an evidence object is made epistemically available without automatically becoming truth, belief, memory, certification, decision or authority.

2. Distributed, non-sovereign architectural identity

ACHILLEION is a distributed and non-sovereign architectural subject. No language model, writer, operator, memory component or application domain individually constitutes the identity of the system. Models are replaceable cognitive organs. Continuity is located in invariants, relations, provenance and auditable genealogy.

3. Models as replaceable cognitive organs

Because the identity of the system is not constitutionally assigned to any single model, model replaceability without replacement of the system is a FORMALIZED consequence of the distributed-identity principle. Operational replacement while preserving continuity has not been traversed or experimentally demonstrated. The intended continuity resides in the constitutional framework, relations, provenance and auditable genealogy.

4. Constitutional cognitive cycle

Observation → State → Context → Interpretation → Proposed Decision → Memory → Certification

“Memory” in this cycle does not authorize canonical persistence before certification. Memory consultation, construction of a memory candidate and mutation of persistent memory are semantically distinct operations.

6. Observational identity and provenance

Under Protocol V1, every epistemic object admitted to the governed lifecycle is required to possess observational identity, provenance, verifiable state and transition history. Implementation has been verified only within the bounded, non-persistent kernel perimeter. Within that scope these mechanisms are IMPLEMENTED; the statement does not extend automatically to every component of the architecture.

7. Fail-closed admission

Admission is fail-closed: an object is admitted only when the required conditions are met; otherwise it is rejected. This property is IMPLEMENTED within the bounded kernel perimeter.

8. HELD, rejection and re-observation

An object may be placed in a HELD or suspended state rather than admitted; it may be rejected; or it may be re-observed. These transitions are IMPLEMENTED within the bounded kernel perimeter. HELD is not memory; it is a way of holding an object without commitment.

9. Revocation without retrospective erasure

Revocation changes the explicit state of an object while preserving its identity, provenance, receipt and history. Within the bounded in-process scope, an explicit revocation transition is IMPLEMENTED, and identity, provenance and a transition receipt are preserved within that verified scope. NOT_DEMONSTRATED: durable preservation across storage and restart, reconstruction of the revocation genealogy, durable historical replay, and revocation as a correction of epistemic truth.

10. Receipt and provenance boundaries

Receipt generation is IMPLEMENTED within the bounded in-process scope. No durable committed execution receipt currently exists. The private repository is not publicly inspectable; a provenance reference may be cited only as a sanitized, non-public provenance reference and is not a public verification source.

11. Replay versus deterministic behavior

Deterministic observational identity and deterministic transition behavior are IMPLEMENTED within the bounded kernel perimeter. NOT_DEMONSTRATED: replay from persisted epistemic history, reconstruction after restart, durable receipt-chain replay and reconstruction of a persistent epistemic genealogy. Replay is not used as a synonym for determinism.

13. Permanence plus plasticity

Permanence is continuity of identity, invariants and genealogy; plasticity is the capacity for states, interpretations and memories to change without retrospective erasure. As a constitutional principle this is FORMALIZED. Re-observation, in-process revocation and deterministic transition behavior are separately IMPLEMENTED within the bounded kernel. Their existence does not constitute an in-memory realization of the whole principle. Canonical persistent permanence-plus-plasticity remains NOT_DEMONSTRATED.

14. AUTHORITY=NONE and the Safety Boundary

No object is automatically promoted to truth, belief, memory, certification, decision or authority. The Safety Boundary separates observation, interpretation, proposal, mutation and certification. Authority separation is IMPLEMENTED within the bounded kernel perimeter. The permanent formula holds: algorithmic execution is necessarily automatic; epistemic assimilation must not be.

15. REALIZATION / SIGNIFICANCE / LIMIT

Realization: the bounded kernel and distinct memory artifacts. Significance: they make observable identity, provenance, admission, HELD, rejection, re-observation, revocation and receipt possible within a governed perimeter. Limit: they do not authorize the conclusion that the architecture is cognitively integrated, that canonical memory is being assimilated, or that any stronger cognitive property is demonstrated.

16. Explicit NOT_DEMONSTRATED boundary

Operational traversal outside isolated harnesses; persistent replay and reconstruction; durable revocation genealogy; end-to-end governed memory assimilation; experimental demonstration; independent replication; controlled baseline comparison; cross-domain transfer; RCC as an empirically validated metric; certified cognitive advantage; consciousness; general cognition; autonomous authority; autonomous self-audit; L6-beta; L7–L12; TELOS; epistemic truth; and persistent assimilation as an operational fact.
