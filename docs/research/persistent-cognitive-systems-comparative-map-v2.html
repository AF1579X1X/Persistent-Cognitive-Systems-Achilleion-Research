Persistent Cognitive Systems — Comparative Map V2

A dated, source-bound and multidimensional map governed by Comparative Methodology V2.

1. Document status and snapshot date

This dated public research statement has snapshot date 2026-08-04. The Protocol V1 Freeze remains in force; “V2” identifies the second comparative map and does not declare Protocol V2. AUTHORITY=NONE remains invariant. Its categories and criteria are a proposed formalization. Evidence quality for the map as an artifact: DOCUMENTATION_ONLY. The existing Italian comparative article is preserved at its current URL as a dated genealogical snapshot. V2 does not call it false or obsolete and does not replace it silently. 3. Methodological reference

This map applies the proposed Comparative Methodology V2. Each row names a comparison unit, binds its bounded description to exact primary sources, distinguishes documented capabilities from observed behavior, and reports UNKNOWN, NOT_APPLICABLE, IMPLEMENTATION_DEPENDENT or NOT_DEMONSTRATED where appropriate. No controlled baseline experiment has been performed.

4. Category map

  • Academic cognitive architectures: Soar and ACT-R.
  • Research proposals and systems for LLM memory: CoALA and MemGPT; Letta is recorded separately as a current stateful-agent platform.
  • Agent orchestration and autonomous-agent projects: LangGraph, AutoGPT Platform, AutoGPT Classic and current BabyAGI.
  • Local or domain-operational systems: Home Assistant Recorder, openpilot and Freqtrade.
  • Protocols, commercial platforms and edge infrastructure: Model Context Protocol, Microsoft Copilot Studio Memory, Edge Impulse and NVIDIA Jetson.
  • Reference literature: lifelong-learning-of-LLM-agents research is contextual literature, not an executable system row.
  • Research architecture under examination: ACHILLEION/Q_ANIMA.

5. Comparison-dimension definitions

  • Persistence: source-described state retention across invocations or restart; in-run memory is not automatically durable persistence.
  • State and memory: representation, storage, access and inspectability described by the source.
  • Safety or permission boundary: source-described constraints, human control or action gating; not a global rating of safety.
  • Operational scope: the domain and granularity of the comparison unit.
  • Epistemic governance: explicit admission, provenance, suspension, revocation, receipt and authority separation.

7. System-by-system notes

  • Soar and ACT-R: memory constructs inside a cognitive architecture do not by themselves answer whether state survives a process restart.
  • CoALA, MemGPT and Letta: a conceptual taxonomy, a research system described in a paper, and a current platform are separate comparison units.
  • AutoGPT and BabyAGI: current projects are separated from their historical forms; genealogy is part of the evidence record.
  • Home Assistant, openpilot and Freqtrade: each is operational in a specific domain, so persistence and safety claims remain domain-bound.
  • MCP, Edge Impulse and Jetson: protocol or platform affordances do not determine the behavior of every implementation built on them.
  • Lifelong LLM-agent research: the roadmap paper is retained as reference literature for the field, not as a system row.

8. Proximity without equivalence

Similarity is assessed dimension by dimension. Letta is close on documented database-backed agent memory; LangGraph on configurable state persistence; Soar and ACT-R on explicit memory architectures; operational systems on durable domain state; and MCP on composable context exchange. None of these proximities establishes architectural equivalence, an absolute closest match, uniqueness, superiority or inferiority.

9. ACHILLEION/Q_ANIMA — REALIZATION / SIGNIFICANCE / LIMIT

REALIZATION: bounded kernel mechanisms are IMPLEMENTED within the non-persistent VC-EP1 perimeter. Test definitions were inspected and a prior audit reported observed executions, but the results were not reproduced in the normalization task and are not preserved by a durable committed execution receipt.

SIGNIFICANCE: the realization makes governed handling of an epistemic object possible within that perimeter while maintaining AUTHORITY=NONE and non-promotion to truth, belief, memory, certification, decision or authority.

LIMIT: persistent operational traversal, canonical memory assimilation, durable replay and reconstruction, durable revocation genealogy, experimental demonstration, replication, controlled baseline comparison, cross-domain transfer and certified cognitive advantage remain NOT_DEMONSTRATED. Q_ANIMA is the first FORMALIZED empirical-domain designation; its efficacy and general cognitive significance are NOT_DEMONSTRATED.

10. Evidence gaps

The map does not independently execute any surveyed system. Some dimensions are unresolved because the authoritative source does not address them, especially durable restart semantics, provenance, revocation and epistemic certification. Commercial preview behavior may change after the snapshot. For ACHILLEION/Q_ANIMA, private evidence is sanitized and not publicly inspectable. No controlled experiment places the systems on equal tasks, models, data, costs or environments.

11. NOT_DEMONSTRATED comparative conclusions

The map does not demonstrate that any surveyed system is cognitively equivalent to another; that ACHILLEION/Q_ANIMA is unique or superior; that governed memory causes better performance; or that any system possesses consciousness, general cognition or autonomous epistemic authority.
